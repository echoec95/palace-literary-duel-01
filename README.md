# 紫禁城文鬥風雲

國中國文學習 × 宮廷敘事 × 文字解謎的網頁遊戲原型。此專案從御花園單關垂直切片開始，逐步擴充至十二關；目前的關卡資料與介面仍在持續開發。

## 開始開發

需求：Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

依終端機顯示的網址在瀏覽器開啟原型。執行 `npm run build` 可產生靜態建置檔。

## 專案內容

- `src/data/`：關卡、角色、對話與題目資料，供前端按 ID 引用。
- `public/assets/`：場景、角色、道具、UI 與特效素材。

## 目前範圍

已建立十二關資料骨架與關卡選擇首頁，並完成御花園首關的可玩原型：線索調查、五題核心題、提示與解析、補救練習、結算、關卡解鎖及瀏覽器本機存檔。其餘十一關與圖片素材待後續製作；題目正誤、解鎖與獎勵由程式規則處理。
